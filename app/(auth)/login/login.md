## 3. UI

### 3.0 이메일 입력
- **기능**: 회원 이메일을 입력한다.
- **규칙**:
  - 필수 입력.
  - 로그인 버튼을 눌렀을 때 비어 있거나 이메일 형식이 아니면 입력란 아래에 오류 문구를 표시한다.
- `❓` 오류 문구 내용

### 3.1 비밀번호 입력
- **기능**: 회원 비밀번호를 입력한다.
- **규칙**:
  - 필수 입력. 입력값은 가려서 표시한다.
  - 로그인 버튼을 눌렀을 때 비어 있으면 입력란 아래에 오류 문구를 표시한다.
- `❓` 오류 문구 내용

### 3.2 로그인 버튼
- **기능**: 입력한 이메일·비밀번호로 로그인을 요청한다.
- **규칙**:
  - 버튼은 항상 누를 수 있다. 입력 오류가 있으면 요청하지 않고 해당 입력란에 오류 문구를 표시한다 (3.0, 3.1).
  - 성공 시 로그인 상태가 되고 **직전 화면으로 복귀**한다. 직전 화면이 없으면(로그인 화면으로 바로 진입) **메인 화면**으로 이동한다.
  - 실패 시 오류를 안내하고 로그인 화면에 머문다.
  - 비밀번호를 **5회 연속** 틀리면 **10분간** 로그인을 잠근다.
- `❓` 로그인 실패 안내 문구
- `❓` 잠금 중 안내 문구(남은 시간 표시 여부), 잠금 대상(계정 / 기기), 실패 횟수 초기화 조건(로그인 성공 시 등)

### 3.3 로그인 옵션
- `❓` 자동 로그인 / 이메일 저장 / 비밀번호 보기 제공 여부

### 3.4 하단 링크
- **기능**: 로그인 외 회원 관련 화면으로 이동한다.
- **규칙**:
  - **회원가입**: 누르면 회원가입 화면으로 이동한다.
- `❓` 추가 링크 제공 여부 (비밀번호 찾기 / 이메일 찾기)

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 기본 | 첫 진입 | 이메일·비밀번호 입력란, 로그인 버튼, 회원가입 링크 표시 |
| 입력 오류 | 버튼 클릭 시 필수값 누락·이메일 형식 오류 | 해당 입력란 아래 오류 문구 · `❓` 문구 |
| 로딩 | 로그인 요청 처리 중 | `❓` (로딩 표시·중복 요청 방지) |
| 성공 | 인증 성공 | 직전 화면 복귀, 없으면 메인 화면 |
| 인증 실패 | 이메일·비밀번호 불일치 | 오류 안내 후 화면 유지 · `❓` 문구 |
| 잠금 | 비밀번호 5회 연속 실패 | 10분간 로그인 불가 · `❓` 안내 문구 |
| 에러 | 서버·네트워크 오류 | `❓` |
